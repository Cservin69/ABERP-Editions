# Format: <file>:<fname>  (line numbers dropped so a benign shift never churns
# it — cf. CHECK 10k). One line per RUNTIME fn that writes the audit ledger
# (table OR mirror) and whose connection provenance is NOT the shared
# `aberp_db::Handle` writer, as classified by
# tools/adr0099_audit_writer_scan.awk. Every entry below is a SANCTIONED
# non-shared writer with the reason it cannot fork the `aberp serve` writer.
#
# NOTE (ADR-0099 R2): this gate covers the SECOND-WRITER class. The seq-2508
# incident was NOT that class — it was a lost DB commit (R2.2). Kept because the
# second-writer class is real and recurred four times, not because it explains
# seq 2508.
#
# Anything NOT on this list that the scanner verdicts READ_CLONE, INDEP_OPENER
# or UNCLASSIFIED fails the build. Unlike CHECK 10M this is not a ban-list of
# known-bad names: the scanner fires on the WRITE and demands a provable
# provenance for it, so an unrecognised one is RED by default.
